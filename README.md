# Вопросы из источников / Булактардан алынган суроолор

Основной набор для подготовки к ОРТ на русском и кыргызском языках: математика, аналогии и дополнение предложений, грамматика, чтение, биология, химия, физика, история и английский язык. Содержит условия, варианты ответов, объяснения и необходимые изображения.

Орус жана кыргыз тилдеринде ЖРТга даярдануу үчүн негизги топтом: математика, окшоштуктар жана сүйлөмдөрдү толуктоо, грамматика, окуп түшүнүү, биология, химия, физика, тарых жана англис тили. Шарттар, жооптордун варианттары, түшүндүрмөлөр жана керектүү сүрөттөр камтылган.

## Для ORT+

- Версия: **1.0.0**.
- Вопросов: **13399**, текстов чтения: **90**.
- Изображений: **1744**, ZIP: **17,474,001 байт**.
- Языки: русский и кыргызский. Установка из GitHub Releases, затем работа офлайн.
- Каталог: [ORT-Catalog](https://github.com/Umar151515/ORT-Catalog).

`manifest.json` описывает текущий проверенный выпуск. Файл
`questions-v1.0.0.zip` загружается в **Releases**, а не коммитится
в основную ветку. В корне ZIP находятся `ort_bank.db` и только необходимые
этому набору изображения из `images/`.

Для обновления подготовьте новый ZIP автоматическим сборщиком ORT+, создайте
Release с тегом `v1.0.0` (для следующего выпуска измените версию),
прикрепите соответствующий ZIP и после публикации замените `manifest.json`.
Содержимое уже опубликованного ZIP под прежней версией не заменяйте.

Материалы могут содержать неточности. Происхождение и проверка прав на материалы
определяются владельцем набора; лицензия автоматически не назначается.
